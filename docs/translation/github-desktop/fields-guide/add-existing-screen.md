# 📂 Add Existing Repository（既存リポジトリ追加）

GitHub Desktop の「Add Existing Repository」画面の入力フィールドと意味をまとめたガイドです。

---

## 📌 画面の目的
- すでにローカルにあるフォルダを Git 管理に追加する
- GitHub Desktop で管理できるようにする

---

## 🧭 入力フィールド一覧

| フィールド名 | 日本語 | 説明 |
|--------------|--------|------|
| Local Path | フォルダパス | 追加したいローカルフォルダ |
| Choose… | フォルダ選択 | フォルダを選ぶボタン |
| Add Repository | 追加 | GitHub Desktop に登録するボタン |

---

## 📝 注意点
- すでに .git があるフォルダはそのまま追加される
- .git がない場合は Git 初期化が必要
