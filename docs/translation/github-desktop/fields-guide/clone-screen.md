Clone Repository 画面ガイド（Screen Guide）
このページでは GitHub Desktop の「Clone Repository」画面 について、
画面構造・ボタンの意味・操作の流れを日本語で整理しています。

🖼 スクリーンショット（全体）

【スクリーンショット挿入枠】
![alt text](<Clone Repository-up-1.png>)

📌 1. この画面の目的
GitHub 上にある既存リポジトリをローカルにコピーする

他の端末で作業しているプロジェクトを取り込む

チームメンバーのリポジトリを取得する

後継者が迷いやすいポイント：

「Clone」は“新規作成”ではなく“コピーして持ってくる”操作

保存先フォルダを間違えると混乱しやすい

🧩 2. 画面構造（番号つき）

【番号つきスクショ挿入枠】
![alt text](<Clone Repository-URL-1.png>)

● ① GitHub.com タブ
GitHub アカウントに紐づくリポジトリ一覧が表示される。

● ② URL タブ
URL を直接入力してクローンできる。

● ③ Local Path（保存先）
ローカルに保存するフォルダを指定する欄。

● ④ Clone ボタン
指定したリポジトリをローカルにコピーする。

🛠 3. 操作手順（Step-by-Step）
GitHub Desktop を開く

File → Clone Repository を選択

クローンしたいリポジトリを選ぶ

Local Path（保存先）を確認

Clone をクリック

ローカルにコピーされ、GitHub Desktop に登録される

⚠️ 4. よくあるミス・注意点
保存先フォルダを間違えると後で迷う

すでに同名フォルダがあるとエラーになる

Private リポジトリは GitHub ログインが必要
